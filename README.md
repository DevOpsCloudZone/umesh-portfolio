# Umesh Aveti - Portfolio

Static portfolio website built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Push the repository to GitHub, then go to:

Settings → Pages → Build and deployment → Deploy from a branch

Select the `main` branch and `/ (root)` folder, then Save.

Update the placeholder GitHub, LinkedIn and email links in `index.html` before publishing.
